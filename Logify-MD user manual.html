📘 Logify MD: User Manual & Deployment Guide

Version: 1.0 (Universal NoSQL Model)
Target Audience: Clinical Leads, Audit Managers, Doctors

1. Introduction

Logify MD is a "Universal" clinical data collection app. Unlike traditional hospital software that requires a programmer to add new fields (like "Ferritin" or "Covid Status"), Logify MD allows you to invent new forms on the fly.

  • Frontend: The screen you see (React).
  • Backend: The "clerk" that handles data (Node.js).
  • Database: The "filing cabinet" (MariaDB/SQL).

2. Software Requirements (The Toolbelt)

Before you can run the app, you need three pieces of free software installed on the "Host Computer" (the laptop or server running the system).

1. Node.js (LTS Version)

  • What it is: The engine that runs the application.
  • Download: nodejs.org (Choose "LTS" - Long Term Support).
  • Action: Install it and just click "Next" until finished.

2. Visual Studio Code (VS Code)

  • What it is: The control panel where you will start and stop the app.
  • Download: code.visualstudio.com

3. MariaDB or XAMPP (The Database)

  • What it is: The place where data is actually stored.
  • Note: If you already have a hospital SQL server, you can use that. If not, install XAMPP to get a local database running quickly.

3. Database Setup (The Filing Cabinet)

You need to create the "Universal Vault" inside your SQL database. This only needs to be done once.

  1. Open your Database Manager (e.g., phpMyAdmin or HeidiSQL).
  2. Create a new Database named: research_data (or select your existing one).
  3. Go to the SQL tab.
  4. Copy and Paste this command to create the master storage table:
CREATE TABLE IF NOT EXISTS study_records (
    id INT AUTO_INCREMENT PRIMARY KEY,
    project_id VARCHAR(50) NOT NULL,    -- e.g. "Hematology_Audit_2026"
    patient_mrn VARCHAR(50),            -- e.g. "MRN-12345"
    data_payload JSON,                  -- Stores ALL fields (Age, Hb, Diagnosis...)
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

5. Click Go / Run. You should see a green success message.

4. Configuration (Connecting the Wires)

Now you must tell the "Clerk" (Server) where the "Filing Cabinet" (Database) is located.

  1. Open the project folder in VS Code.
  2. Open the file named server.js.
  3. Look for the DB_CONFIG section at the top. Update it with your specific details:
const DB_CONFIG = {
  host: 'localhost',       // Use 'localhost' if DB is on this laptop. Use IP if on server.
  user: 'root',            // Your Database Username
  password: 'your_password', // Your Database Password
  database: 'research_data' // The name of the database you created in Step 3
};

4. Save the file (Ctrl + S).

5. How to Run the App (Daily Routine)

To start the application, you need to turn on both the Backend (Server) and Frontend (Screen).

Step A: Open the Terminal

In VS Code, go to the top menu: Terminal → New Terminal.

Step B: Start the Server (The Backend)

  1. In the terminal, type: node server.js
  2. Press Enter.
  3. You should see: 🚀 Universal Server running on http://localhost:3000

Step C: Start the App (The Frontend)

  1. Click the + (Plus) icon on the terminal (top right of the terminal panel) to open a second window.
  2. Type: npm run dev
  3. Press Enter.
  4. You will see a Local URL (e.g., http://localhost:5173). Ctrl + Click that link to open the app in your browser.

6. Using the App (For Doctors)

Tip: You can create unlimited "Projects" (Audits) inside the app. Each one is separate.

Creating a New Study

  1. Log in with your Master Password.
  2. Click "New Project".
  3. Give it a name (e.g., "Anemia Audit 2026").
  4. Define your Fields:
    • Click "Add Field".
    • Type "Hemoglobin", select "Number".
    • Type "Ferritin", select "Number".
    • Type "Smoker?", select "Yes/No".
  5. Click Save Project.

Collecting Data

  1. Click "Collect Data" on your project.
  2. Enter the patient details.
  3. Click Save.
    • ✅ Green Checkmark = Saved to the SQL Database safely.
    • ❌ Red X = Connection error (Check if node server.js is running).

Exporting to Excel

  1. Click "View Data".
  2. Click the "Export to Excel" button.
  3. The app will automatically organize all your random fields into neat columns (.csv file) ready for analysis.

7. Troubleshooting Common Issues

Problem Solution
"Connection Failed" Error 1. Is node server.js running in the terminal?
2. Is the Database Password in server.js correct?
"Save Failed: Table doesn't exist" You skipped Step 3. Run the SQL code to create the study_records table.
"Network Error" on Phone Ensure your phone is on the same WiFi as the laptop. You may need to use the Laptop's IP address (e.g., 192.168.1.15:5173) instead of localhost.
